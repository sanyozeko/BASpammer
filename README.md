# BASpammer

Аддон для World of Warcraft 3.3.5a (WotLK). Отправляет заданный текст в выбранный
номерной канал с заданным интервалом — для объявлений о наборе в рейд, продаже
и тому подобного.

Оригинальный аддон написали **Bigalex** и **irlyhatemyselfandyou**; здесь его
переработанная версия.

## Возможности

- 20 шаблонов текста, до 255 байт каждый
- Выбор канала по названию, а не по номеру: номера между сессиями меняются,
  аддон находит канал по имени сам
- Интервал от 10 секунд, со случайным разбросом ±2 с (на минимуме разброса нет)
- Текст, канал, шаблон и интервал меняются прямо во время спама
- Обратный отсчёт до следующей отправки
- Вставка ссылок на квесты и достижения через SHIFT + клик
- Метки рейда через правый клик по полю текста
- Три способа вызова окна на выбор: кнопка на миникарте, иконка на экране
  или надпись. Значок показывает состояние: красный — молчит, зелёный — спамит
- Команда `/baspammer` (или `/bas`)

## Установка

Скопировать папку `BASpammer` в `World of Warcraft\Interface\AddOns\`.

После добавления новых файлов текстур клиент 3.3.5 нужно перезапустить
полностью — `/console reloadui` перечитывает только Lua и XML.

## Настройки

Настройки хранятся отдельно для каждого персонажа (`SavedVariablesPerCharacter`).
Кнопка-шестерёнка в заголовке окна открывает выбор способа вызова.

## Разработка

Текстуры интерфейса (`BASpammer/Textures/*.tga`) нарисованы скриптом и лежат
в формате TGA 32 бита без сжатия — другого формата клиент 3.3.5 не понимает.
Стороны каждой текстуры кратны степени двойки.
